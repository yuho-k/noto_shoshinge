# 「正信偈講義」データ

本データは、能登光誓寺旧蔵「正信偈講義」（仮題）の本文をテキストデータ化し，[OpenCHJ OCX Standard](https://openchj.github.io/ocx-standard)に準拠（＋α）する形でXML化したものです。

具体的には，以下の情報について校訂を行いました。

- 文境界: ```<tei:s>……</tei:s>``` or ```<ocx:eos/> ```
  - 底本は句読点「。」「、」の区別がなく全て朱の「、」が打たれる。これを入力した上で，文境界と判断できる箇所は句点「。」とし，タグを付した。
  - 句点が打たれないが，明らかに文境界と認められる箇所にもタグを付した。空要素は，```<tei:sp>``` などが絡んでペアタグが付せない箇所にのみ使用した。
- 会話: ```<tei:sp who="……">「……」</tei:sp>```
  - 会話文と判断できる箇所に「　」，spタグ・話者情報を付した。
  - 例: ```<tei:sp who="日本人">「日本ニハ丗一文字ノ歌ヲヨミマスル。」</tei:sp>```
- 引用: ```<tei:q>……</tei:q>```
  - 例: ```サテ帰ノ字ノ訓ニ、<tei:q>「帰ノ言ハ至也」</tei:q>トアル。 ```
  - 実際には会話文と引用文の区別が難しいところもあるが，暫定的に分けた。
- 濁点無表記箇所: ``` <ocx:vmark orig="原文">…</ocx:vmark> ```
  - 例: ``` 夫ナレ<ocx:vmark orig="ハ">バ</ocx:vmark>コソ ```
  - 朱点がある場合，@hand
- ルビ: 右ルビの場合 ```<ocx:r rt="ルビ">親字</ocx:r>```,  左ルビの場合 ```<ocx r lrt="ルビ">親字</ocx:r>```
  - 例: ```<ocx:r rt="アサノタクミノカミ" lrt="ヱンヤハングワン">浅野内匠頭</ocx:r>```
- 踊り字: ``` <ocx:odoriji orig="原文（踊り字）">…</ocx/odoriji> ```
  - 例: ``` 只聞テ疑ハル<ocx:odoriji orig="ヽ">ル</ocx:odoriji>斗 ```
- 行境界 ``` <tei:lb/> ```、頁境界 ``` <tei:pb n="…"> ```
  - 丁数は、表を "o", 裏を "u" とした。（ソートの便宜）

本書は近世の加賀・能登方言や，当期の節段説教の姿を知ることができる貴重な資料です。書誌・意義などの詳細については下記論文をご参照ください。
